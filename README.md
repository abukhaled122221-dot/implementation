# THIQA — منصة التوصية الذكية لتأمين السيارات

هذا المشروع هو تنفيذ للمرحلة الثانية (فيز 2) من نظام THIQA، مبني على設計 المرحلة الأولى (راجع `docs/THIQA_Car_Insurance_Report.pdf`، الفصل 3).

## نظرة عامة على النظام

تتبع THIQA بنية معمارية ثلاثية الطبقات تفصل 명확ًا بين المسؤوليات:

```
المستخدم → الواجهة الأمامية (HTML/JS) 
                        │
                        ▼
              خادم Node.js (Express) — طبقة البوابة
                        │  HTTP POST /api/recommend
                        ▼
              خدمة Python (FastAPI) — طبقة الوكلاء
        الوكيل 1 (الاستلام) → الوكيل 2 (التوصية) → الوكيل 3 (الشرح)
                        │
                        ▼
              محاكاة شركات التأمين — طبقة تكامل البيانات (قابلة للاستبدال بواجهات حقيقية)
```

### وظائف كل طبقة

**الطبقة 1: خادم Node.js (Express)**
- يخدم الواجهة الأمامية الثابتة من مجلد `public/`
- يعمل كبوابة (gateway) لتحويل запросов الواجهة الأمامية إلى خدمة الوكلاء Python
- سيُضيف لاحقًا مكونات المصادقة (User/Admin) والتكامل مع قاعدة البيانات (حسب مخطط ERD في التقرير)

**الطبقة 2: خدمة Python (FastAPI)**
- تحتوي على منطق الوكلاء الثلاثة الذكيين:
  - **الوكيل 1 (الاستلام والجلب)**: يستلم بيانات العميل، يتحقق من صحتها، ويستعلم شركات التأمين (الوهمية حاليًا)
  - **الوكيل 2 (التوصية)**: يقيّم ويرتب عروض التأمين باستخدام معايير موزونة وفق أولوية العميل
  - **الوكيل 3 (الشرح)**: يولد تفسيرًا مبسطًا بالعربية لسبب اختيار التوصية ولماذا لم تُختر البدائل
- قابل للتوسيع بسهولة بنماذج تعلم آلي حقيقية مستقبلاً

**الطبقة 3: محاكاة شركات التأمين**
- تُحاكي استجابات أربع شركات تأمين سعودية (التعاونية، الراجحي تكافل، ميدغلف، ACIG)
- مصممة لاستبدالها بواقع API حقيقيين لاحقًا دون الحاجة لتعديل كود الوكلاء (لأنها تتعامل مع شكل بيانات موحد)

## التشغيل محليًا

### 1) تشغيل خدمة الوكلاء (Python) — في نافذة طرفية أولى
```bash
cd agents
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

### 2) تشغيل خادم Node.js الرئيسي — في نافذة طرفية ثانية
```bash
cd server
npm install
npm start
```

### 3) فتح الواجهة في المتصفح
```
http://localhost:3000
```
